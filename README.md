# Textborn

A text-native side-view platformer built with Godot 4.7.2.

## Vision
Characters and environments are rendered from glyphs, numbers and symbols,
rather than conventional PNG character sprites.

## Current character system
- Procedural glyph-based human silhouette
- Runtime idle, walk, run, jump and attack poses
- Text-rendered sword and slash effects
- CharacterBody2D collision and platform physics

## Controls
- Left / Right: move
- Shift: run
- Space / Enter: jump
- X: attack

## Run
    godot --path .
